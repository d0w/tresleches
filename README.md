# Tres Leches

Implementation of mesh routers, load-balancers, and firewalls because why not. This is a (probably poor) implementation of a router where the end goal is one that handles layer 4 requests in a decentralized manner rather than on the client-server model. This means that a single TCP/UDP request can connect with multiple clients to complete a segment and vice versa.

This is primarily an experimentation project.
