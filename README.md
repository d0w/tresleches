# Tres Leches
Reinventing L4 protocols to be decentralized because why not. This is a (probably poor) implementation of a TCP-like router that handles layer 4 requests in a decentralized manner rather than on the client-server model. This means that a single TCP request can connect with multiple clients to complete a TCP segment. 

This does not try to reinvent Layer 1-3 or 7. There are plenty of reasons why this isn't needed but if we don't want an internet that can be controlled by a select few, we have to start somewhere and rethink the foundations that computing relies on.
